# Phạm vi chức năng kiểm thử HW02

Các chức năng do sinh viên chọn:

| Pool | Specification ID | Feature | Platform | Artifact ID |
|---|---|---|---|---|
| A | FR-01 | Đăng ký tài khoản | Web | FR-01 |
| B | FR-07 | Giỏ hàng | Web | FR-07 |
| C | FR-14 | Quản lý danh mục | Web Admin | FR-14 |
| D | FR-06 | Xem chi tiết sản phẩm | Mobile | FR-06-MOBILE |

`FR-06-MOBILE` là mã tổ chức tệp để thể hiện nền tảng, không phải mã yêu cầu mới. Truy vết nghiệp vụ về FR-06; thực thi và thu bằng chứng trên ứng dụng Mobile.

Mỗi chức năng thực hiện cả Domain Testing và Boundary Value Analysis. Quy tắc nghiệp vụ lấy từ đặc tả hệ thống/API được cung cấp; danh sách này không thay thế đặc tả.
