## Điều kiện tiên quyết và dữ liệu

- Danh mục `DM-FR14-BAOVE` tồn tại.
- Có JWT hợp lệ của tài khoản user thường `test@eshop.com`.

## Các bước tái hiện

1. Đăng nhập bằng tài khoản user thường để lấy JWT.
2. Gửi `DELETE /api/categories/:id` tới ID của `DM-FR14-BAOVE` với token user.
3. Ghi nhận response.
4. Dùng phiên Admin kiểm tra lại danh sách danh mục.

## Kết quả mong đợi

Request bị từ chối vì role không phải Admin và `DM-FR14-BAOVE` vẫn tồn tại.

## Kết quả thực tế

API trả HTTP `200`; `DM-FR14-BAOVE` bị xóa khỏi danh sách.
