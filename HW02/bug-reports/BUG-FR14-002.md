## Điều kiện tiên quyết và dữ liệu

- Có thể đăng nhập bằng tài khoản Admin để mở trang quản lý Danh mục.
- Có tài khoản user thường để thử truy cập phân hệ Web Admin.

## Các bước tái hiện

1. Đăng nhập bằng tài khoản Admin, mở trang quản lý Danh mục và quan sát các mục điều hướng.
2. Dùng tài khoản user thường thử truy cập phân hệ Web Admin.
3. Quan sát tiêu đề và nút trên trang đăng nhập Admin.

## Kết quả mong đợi

Giao diện sử dụng tiếng Việt theo FR-21.

## Kết quả thực tế

- Trên trang quản lý Danh mục, mục điều hướng `Dashboard` vẫn hiển thị bằng tiếng Anh.
- Trên trang đăng nhập Admin xuất hiện sau khi user thường bị chặn, tiêu đề `Admin Login` và nút `Login` vẫn hiển thị bằng tiếng Anh.
